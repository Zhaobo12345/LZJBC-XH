产品概述

产品背景

随着家装行业的不断发展，传统的项目管理方式已无法满足现代家装项目的复杂需求。良造家管理平台旨在通过数字化手段，为家装项目提供一站式管理解决方案，实现项目全生命周期的可视化、规范化管理。

产品定位

良造家管理平台是一个面向家装行业的数字化管理工具，涵盖PC管理端和小程序端，为平台运营人员、服务方（设计师、施工团队、监理人员等）和业主提供全方位的项目管理功能。

产品价值

  • 提升效率：通过数字化流程，减少人工操作，提高项目管理效率
  • 规范管理：标准化合同流程和任务管理，确保项目质量
  • 信息透明：实时同步项目进度，确保各方信息对称
  • 便捷协作：支持多方协作，简化沟通流程
  • 角色清晰：明确区分不同角色的职能和权限，避免操作混乱

关键交互流程

PC端合同审核流程

1. 运营人员登录后进入合同列表页

2. 点击合同名称或"去审核"按钮进入合同详情页

3. 查看合同基本信息、合同正文、阶段任务、附件

4. 点击"审核通过"或"驳回"按钮

5. 驳回时需填写驳回原因

6. 审核后返回列表页，合同状态更新

服务方任务执行流程

1. 服务方用户进入任务列表页，查看待执行任务

2. 点击任务卡片进入任务详情页

3. 查看执行标准、确认标准、担责标准

4. 点击"上传记录"上传执行过程照片/视频

5. 执行完成后点击"提交验收"

6. 等待确认人确认验收

业主任务确认流程

1. 业主用户进入首页，查看待确认事项

2. 点击待确认任务进入任务详情页

3. 查看执行人信息、执行记录（照片/视频）

4. 确认合格：点击"确认验收"，可选填评价

5. 不合格：点击"驳回"，填写驳回原因

6. 驳回后任务返回执行中状态，需重新执行

对账单确认流程

服务方提交：

1. 服务方进入对账单列表页，点击新增按钮

2. 选择关联合同（自动带出确认人）

3. 选择账单类型、输入金额、填写用途描述

4. 提交后通知业主确认

业主确认：

1. 业主进入对账单列表页，查看待确认对账单

2. 点击卡片进入详情页

3. 确认无误：点击"确认无误"

4. 有问题：点击"驳回"，填写驳回原因

5. 确认后状态变为"已生效"，等待服务方上传支付凭证

文档结构说明
每个页面规格文档包含以下章节：
1. 页面概述（基本信息、业务目标）
2. 页面结构（布局图、组件清单）
3. 字段定义（数据来源、校验规则、显示规则）
4. 组件规格（按钮、表单、卡片等详细规格）
5. 交互流程（点击、提交、跳转等流程）
6. 状态变化（状态映射表）
7. 异常处理（错误提示、空状态）
8. API对接（接口调用时机、参数、响应）
9. 权限控制（角色权限矩阵）

建议开发顺序：

  1. 先实现PC端合同模块（登录→列表→详情→编辑）
  2. 再实现服务方小程序项目模块（首页→项目列表→项目详情）
  3. 然后实现任务模块（任务列表→任务详情→任务验收）
  4. 最后实现业主小程序和其他辅助功能
