5.5 对账单卡片规格
展示区域 字段项 数据来源 显示规则

5.6 新增对账单表单规格
字段 类型 必填 说明
关联合同 下拉选择 ✅ 选择关联的合同，选择后自动带出确认人信息
确认人 展示 — 选择合同后自动显示，格式：角色标签 + 姓名（如：业主 李先生）
账单类型 胶囊选择 ✅ 单选：工友工资、辅料费、措施费、保险费、工长工资
本次金额 数字输入 ✅ 支持输入负数用于冲销/退款
用途描述 文本输入 ✅ 最大200字，实时字数统计
表单提交规则

1. 所有必填字段填写完整后方可提交

2. 金额支持负数，用于冲销错误账单或退款场景

3. 提交后对账单状态变为"待确认"，并通知确认人

5.7 状态流转规则
待确认(pending) → [确认人确认] → 已生效(effective) → [服务方上传支付凭证] → 已支付(paid) ↓ [确认人驳回] → 已驳回(rejected)
状态 状态值 说明 可执行操作
待确认 pending 服务方提交后，等待确认人确认 确认人：确认/驳回；提交人：无操作
已生效 effective 确认人已确认，等待服务方上传支付凭证 服务方：上传支付凭证
已支付 paid 服务方已上传支付凭证，账单完成 查看详情
已驳回 rejected 确认人驳回，需要修改后重新提交 提交人：重新编辑提交

5.3 状态机（已确认）

合同状态机

拟定中(drafting) → 待审核(pending_review) → 待确认(pending_confirm) → 待签约(pending_sign) → 已签约(signed) ↓ ↑ 审核驳回(platform_rejected) │ │ 变更中(changing) ────────────────────────────────────────────────────┘

任务状态机

待开始(pending) → 执行中(in_progress) → 确认中(confirming) → 已完成(completed)
