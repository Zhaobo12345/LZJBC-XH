五、交互流程
5.1 页面加载流程
1. 用户从合同列表页点击"去审核"或合同名称 2. 页面加载，显示骨架屏（状态横幅+卡片占位） 3. 调用接口 GET /api/v1/contracts/:id 4. 接口返回数据，渲染页面 5. 根据合同状态和用户角色，显示对应的横幅和按钮 6. 页面加载完成，骨架屏消失
加载状态规格

骨架屏显示时长：接口返回前持续显示
超时处理：接口超过10秒未返回，显示"加载失败，请刷新重试"
刷新方式：点击浏览器刷新按钮或F5

5.2 审核通过流程
1. 运营用户点击"审核通过"按钮 2. 弹出确认弹窗，标题"确认审核通过？"，内容"审核通过后合同将进入业主确认环节" 3. 用户点击"确定" 4. 按钮显示加载状态"处理中..." 5. 调用接口 POST /api/v1/contracts/:id/approve 6. 接口返回成功： - Toast中部显示"审核成功"，持续2秒 - 页面刷新，状态横幅变为"待确认" - 审核面板消失 7. 接口返回失败： - Toast中部显示错误信息，持续2秒 - 按钮恢复默认状态
5.3 审核驳回流程
1. 运营用户点击"驳回"按钮 2. 驳回输入框展开（默认收起） 3. 用户输入驳回原因 4. 按钮文案变为"确认驳回"，样式变为红色危险按钮 5. 用户点击"确认驳回" 6. 前端校验驳回原因是否为空： - 若为空：Toast中部显示"请输入驳回原因"，持续2秒，不提交 - 若不为空：继续提交 7. 按钮显示加载状态"处理中..." 8. 调用接口 POST /api/v1/contracts/:id/reject 参数：{ "reject_reason": "驳回原因内容" } 9. 接口返回成功： - Toast中部显示"驳回成功"，持续2秒 - 页面刷新，显示驳回横幅 10. 接口返回失败： - Toast中部显示错误信息，持续2秒 - 按钮恢复默认状态
5.4 导出合同流程
1. 用户点击"导出合同"按钮 2. 按钮文案变为"导出中..."，禁用点击 3. 调用接口 GET /api/v1/contracts/:id/export 4. 接口返回PDF文件流： - 浏览器自动下载文件 - 文件名：合同名称_合同编号.pdf - 按钮恢复默认状态 5. 接口返回失败： - Toast中部显示"导出失败，请稍后重试"，持续2秒 - 按钮恢复默认状态
5.5 分享功能流程
1. 用户点击"分享"按钮 2. 弹出分享面板（底部抽屉） 3. 面板内容： - 分享给微信好友（调用小程序分享API） - 复制链接（生成带share_code的H5链接） 4. 分享给微信好友： - 调用 wx.miniProgram.shareAppMessage - 分享标题：合同名称 - 分享描述：点击查看合同详情 - 分享路径：/pages/contract-detail/index?id={contract_id} 5. 复制链接： - 调用接口 POST /api/v1/shares - 参数：{ "target_type": "contract", "target_id": "{contract_id}" } - 接口返回 share_code - 生成链接：https://h5.liangzaojia.com/share/{share_code} - 复制到剪贴板 - Toast中部显示"链接已复制"，持续2秒

8.2 操作接口
POST /api/v1/contracts/:id/approve

调用时机：点击"审核通过"按钮

请求参数：无

响应数据：

{ "code": 0, "message": "success", "data": { "contract_id": "uuid", "new_status": "pending_confirm" } }

成功处理：Toast提示"审核成功"，刷新页面

POST /api/v1/contracts/:id/reject

调用时机：点击"确认驳回"按钮

请求参数：

{ "reject_reason": "合同金额填写有误，请核实后重新提交" }

响应数据：

{ "code": 0, "message": "success", "data": { "contract_id": "uuid", "new_status": "drafting" } }

成功处理：Toast提示"驳回成功"，刷新页面

9.2 前端权限控制逻辑
// 根据用户角色和合同状态判断按钮是否显示 function shouldShowApproveBtn(userRole, contractStatus) { return userRole === 'operator' && contractStatus === 'pending_review'; } function shouldShowRejectBtn(userRole, contractStatus) { return userRole === 'operator' && contractStatus === 'pending_review'; } function shouldShowExportBtn(userRole, contractStatus) { const allowedStatuses = ['pending_confirm', 'pending_sign', 'signed']; return allowedStatuses.includes(contractStatus) && ['operator', 'initiator', 'service', 'owner'].includes(userRole); } function shouldShowShareBtn(userRole, contractStatus) { return userRole !== 'owner' && contractStatus === 'signed'; } function shouldShowConfirmBtn(userRole, contractStatus) { return userRole === 'owner' && contractStatus === 'pending_confirm'; }
权限验证说明

前端权限控制仅为UI层面，后端接口需独立验证权限。若前端绕过校验调用接口，后端返回40301错误码。
