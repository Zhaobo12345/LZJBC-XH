1.3.4 顶部搜索与筛选条件匹配规则
控件匹配字段匹配方式空 / "全部" 取值行为
模板名称搜索框模板名称模糊匹配：包含输入关键字即命中；忽略大小写、忽略首尾空格为空 = 不限名称
城市下拉城市精确匹配：选项值 = 字段值"全部城市" = 不限；选项值与模板「适用城市」字段一致（北京市 / 南阳市 / 西安市），精确匹配
状态下拉状态精确匹配：启用=active / 停用=inactive"全部状态" = 不限
  • 三个顶部控件之间为 AND 关系：需同时满足名称模糊命中、城市精确相等、状态精确相等。
  • 顶部筛选再与左侧模板类型树叠加，仍为 AND（四类条件全部命中才出现在列表）。
  • 「搜索」按钮（applyFilters）触发按上述条件过滤；「重置」按钮（resetFilters）清空名称/城市/状态并恢复“全部模板”选中，列表与类型树 count 同步刷新。

交互场景效果
打开新建弹窗标题置"新建合同文本模板"；表单全部清空；正文重置为占位文本；城市默认"北京市"；遮罩淡入

插入表格 / 图片 / 链接弹 prompt 输入行数/列数/URL/描述，确认后以 HTML 插入光标处

保存并发布先执行 1.4.3 校验（含同城市启用模板重名校验），通过则关闭弹窗并 Toast"模板已保存并发布"；列表最上方新增一行（状态默认启用）并按当前筛选条件重算列表（applyFilters）

1.4.5 保存流程与状态流转
两种保存动作的差异
新建 / 编辑弹窗底部提供「保存草稿」与「保存并发布」两个动作，二者在校验强度与生成的状态上不同，对应实现分别为 saveDraft() 与 saveTemplate()（status=active）。
维度保存草稿保存并发布
触发按钮保存草稿保存并发布
校验时机提交时提交时
校验强度仅校验「模板名称」非空校验「模板名称 / 模板类型 / 适用城市 / 合同正文」全部必填（规则见 1.4.3）
生成状态草稿（橙色「草稿」徽标，列表可一键「发布」转为启用）启用（绿色「启用」徽标，可直接被新建合同选用）
列表联动新增一行（状态=草稿），「全部模板」计数与对应类型计数 +1新增 / 覆盖一行（状态=启用），计数同步刷新
提示Toast 中部「已保存草稿」Toast 中部「模板已保存并发布」
失败处理名称为空则阻止并聚焦输入框、红框提示任一必填缺失则阻止并红框高亮+弹窗汇总；若同城市下已存在同名启用模板亦阻止（提示“该城市下已存在同名的启用中模板，请勿重复创建”）
状态流转（草稿 / 启用 / 停用）
草稿 ──(列表行「发布」按钮 / publishDraft)──▶ 启用 ──(列表行「停用」/ toggleStatus)──▶ 停用 ▲ │ │ └────────(编辑后点「保存草稿」回退)─────────────────┘ │ 停用 ──(列表行「启用」/ toggleStatus)──▶ 启用
  • 草稿 → 启用：草稿行操作区提供「发布」按钮（publishDraft(id)），点击后状态徽标转「启用」、按钮转为「停用」，模板立即进入可选用范围。
  • 启用 ↔ 停用：见 1.6 启用 / 停用，状态仅影响新建合同可选用范围，不影响已签署或已生成合同。
  • 启用 / 停用 → 草稿：已发布模板在编辑后点击「保存草稿」可回退为草稿态（保留内容、退出选用范围），后续可再次发布。

1.6 启用 / 停用
1.6.1 入口
  • 列表"操作"列的"停用 / 启用"按钮（toggleStatus(id)），依据当前行状态显示相反操作。
1.6.2 停用交互流程
步骤行为
1. 点击"停用"弹出二次确认："确定要停用此模板吗？停用后新建合同将无法选择此模板。"
2. 取消关闭确认框，不执行任何变更
3. 确认执行停用：行加 .disabled、状态徽标转"停用"（灰）、按钮文案"停用"→"启用"；提示"模板已停用，新建合同将无法选择此模板"
1.6.3 启用交互流程
步骤行为
1. 点击"启用"无需确认，直接执行
2. 执行行移除 .disabled、状态徽标转"启用"（绿）、按钮文案"启用"→"停用"；提示"模板已启用，新建合同可选择此模板"
1.6.4 行联动效果
状态变化视觉联动
启用 → 停用整行 opacity 0.6（.disabled）；状态徽标绿→灰；操作按钮"停用"→"启用"；模板名称转灰
停用 → 启用整行恢复不透明；状态徽标灰→绿；按钮"启用"→"停用"；名称恢复主色
1.6.5 影响范围
  • 停用仅影响"新建合同 / 发起变更时可选用模板的范围"，已签署或已生成的合同不受影响。
  • 模板类型树 count 同步（停用模板仍计入总数，仅状态变化，不减少总条数）。

2.6.2 禁用交互流程
步骤行为
1. 点击"禁用"若该模板被引用（data-refs > 0），弹二次确认："该模板已被引用 N 次，禁用后新建合同将无法选择此模板。确定要禁用吗？"；未被引用则直接执行。

步骤行为
1. 点击"启用"无需确认，直接执行
2. 执行卡片移除 .disabled、状态徽标转"启用中"（绿）、按钮"启用"→"禁用"；提示"模板已启用，新建合同可选择此模板"
